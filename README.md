# Apogee icon packs

A collection of icon packs distributed as Apogee-compatible sidecars.

## Licenses

The packs keep the licensing of their upstream icon sets. Full license texts are included next to the icons in
`resources/<pack>/LICENSE` where the upstream provides one.

| Pack | License | Upstream |
|---|---|---|
| `core` | MPL-2.0 (Apogee assets); control glyphs derived from Lucide (ISC) | [Apogee](https://github.com/umbreon-boop/apogee) |
| `feather` | MIT | [Feather](https://github.com/feathericons/feather) |
| `gravity` | MIT | [Gravity UI Icons](https://github.com/gravity-ui/icons) |
| `heroicons-outline`, `heroicons-solid` | MIT | [Heroicons](https://github.com/tailwindlabs/heroicons) |
| `lucide` | ISC | [Lucide](https://github.com/lucide-icons/lucide) |
| `material-design` | Pictogrammers Free License; icons Apache-2.0 | [Material Design Icons](https://github.com/Templarian/MaterialDesign) |
| `sfsymbols` | Apple SF Symbols license; no license is provided by Apple | [SF Symbols](https://developer.apple.com/sf-symbols/) |
| `tabler-filled`, `tabler-outline` | MIT | [Tabler Icons](https://github.com/tabler/tabler-icons) |
